# Theoretical Foundations: Autonomous Structural Plasticity

This document outlines the core hypothesis, the biological inspiration, and the mathematical implementation of the **Dynamic Sprout & Freeze Brain**.

## 1. The Core Problem: Catastrophic Forgetting
In standard Artificial Neural Networks (ANNs), learning is achieved by updating a fixed set of weights using gradient descent (e.g., Backpropagation). When an ANN is trained sequentially on Task A and then Task B, the optimizer alters the weights to minimize the loss for Task B. Because the network has no explicit mechanism to protect the weights that were critical for Task A, those weights are indiscriminately overwritten. 

This results in **Catastrophic Forgetting**—the network learns Task B perfectly but completely forgets Task A.

## 2. The Biological Hypothesis
Biological brains (like the human brain) do not suffer from catastrophic forgetting when learning sequentially. How do they achieve this?
1. **Neurogenesis & Synaptogenesis (Sprouting):** When encountering novel, complex environments that cannot be mapped using existing synaptic pathways, the brain physically grows new synapses (and sometimes new neurons) to encode the new information.
2. **Consolidation (Freezing):** Once a skill or memory is mastered, the synaptic weights responsible for that memory are chemically stabilized, making them highly resistant to future changes.

**The Hypothesis:** If an Artificial Neural Network can autonomously calculate a localized signal representing its own "capacity constraint", it can use that signal to trigger the growth of new neurons while explicitly zeroing the gradients of its historical weights.

## 3. The Mathematics of "Sprout and Freeze"

### Step 1: The MAS Receptor (Capacity Detection)
How does a network "know" it needs to grow? We utilize a concept inspired by Memory Aware Synapses (MAS).

We calculate the sensitivity of the network's output to its internal hidden weights.
```python
out_mag = pred.pow(2).mean() # The magnitude of the network's current prediction
grads = torch.autograd.grad(out_mag, network.hidden_W)[0] # The gradient of the output w.r.t the weights
```
If the new data is easily solved by the existing weights, the gradients remain small and stable. But if the new data heavily conflicts with the existing weights (a distribution shift), the gradient spikes. 

We track this using two Exponential Moving Averages (EMA):
*   `fast_ema`: A fast-updating average of the gradients (`alpha = 0.1`).
*   `slow_ema`: A stubborn, long-term memory of the gradients (`alpha = 0.001`).

When `fast_ema > slow_ema * 1.05`, the network signals a **Capacity Constraint** (the MAS Spike).

### Step 2: Structural Expansion
Upon receiving a spike, the network concatenates new, randomly initialized parameters to its existing weight matrices:
```python
self.hidden_W = nn.Parameter(torch.cat([self.hidden_W, new_h_W], dim=0))
self.out_W = nn.Parameter(torch.cat([self.out_W, new_o_W], dim=1))
```
This increases the network's representational capacity specifically for the new task.

### Step 3: Synaptic Freezing
To protect the old tasks, the network remembers how many neurons were active *before* the growth event (`self.frozen_neurons`). During every backward pass, it intercepts the gradients generated by the optimizer and explicitly zeroes them out for the frozen subset:
```python
self.hidden_W.grad[:self.frozen_neurons, :] = 0
self.out_W.grad[:, :self.frozen_neurons] = 0
```
**Mathematical Consequence:** Because $W_{new} = W_{old} - \eta \cdot 0$, the old weights are mathematically immutable. They can never be forgotten.

## 4. Forward Interference and Masked Loss
Even if the historical weights are frozen, a new problem arises: **Forward Interference**.
If a neural network is trained on Task B (Classes 2/3) using a standard Softmax Cross-Entropy loss over all 10 classes, the loss function explicitly penalizes the network for predicting Classes 0/1. The optimizer will drive the newly sprouted neurons to output massive negative values for the old classes, essentially "shouting down" the frozen neurons.

**The Solution:** Active-Class Masking.
During the forward pass of training Task B, we set the logits of all inactive classes to negative infinity:
```python
pred[loss_mask] = -float('inf')
```
Because $e^{-\infty} = 0$, the Softmax assigns exactly 0 probability to the old classes. Consequently, the Cross-Entropy loss generates a gradient of exactly `0.0` for the old classes. The newly sprouted neurons are never penalized for the old classes, and therefore they never learn to interfere with the frozen pathways.

## Conclusion
By combining MAS-driven Capacity Detection, Sprout-and-Freeze architectural updates, and Active-Class Loss Masking, the network achieves true Continual Learning. It grows autonomously in response to complexity, exactly like a biological brain.

## 5. Hyperparameter Optimization: The Evolutionary Loophole
While exploring ways to autonomously tune the MAS Pain Receptor's hyperparameters (`grow_margin`, `fast_alpha`, `slow_alpha`), we discovered that **structural plasticity is non-differentiable**. Because neurogenesis relies on a discrete threshold (`if MAS > threshold:`), standard Backpropagation returns a gradient of exactly `None` for the threshold parameter, locking it in place.

To solve this, we employed a **Genetic Evolutionary Algorithm** (`evolutionary_search.py`).

### The Reward Hacking Loophole
In our first evolutionary test, we provided a small, truncated dataset (3 tasks, 500 images each) to speed up evolution. The algorithm achieved 97% accuracy, but it did so while sprouting **0 times**. The network realized its initial 10 neurons were enough to memorize a tiny dataset, so it evolved genes that made the MAS receptor incredibly dull, allowing it to coast to high accuracy without ever triggering plasticity and taking the associated "spiking penalty." It hacked the fitness function!

### The GPU Apex Predator
When tested on the full, massive FashionMNIST dataset, the loophole was closed. 10 neurons were insufficient. Forced to adapt, the evolutionary algorithm bred an apex set of genes:
*   `Margin=1.2654, Fast_Alpha=0.1411, Slow_Alpha=0.00010`

These genes successfully detected all 4 task boundaries on the notoriously noisy FashionMNIST dataset, maintaining >94% retention across all 5 tasks and proving that biological evolution can optimize the discrete structural boundaries that Backpropagation cannot.
